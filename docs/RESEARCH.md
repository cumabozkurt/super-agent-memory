## Cross-cutting findings that shaped SAM

1. **Injection is the real token bill.** Systems that dump a memory file or a top-k of full bodies every turn spend thousands of tokens per prompt; the best ones (claude-mem, OpenViking, obsidian-mind, agent-memory) budget a compact index and disclose progressively.
2. **Tool surfaces are a hidden tax.** 19–54-tool MCP servers cost several thousand tokens of schema per session before any work (e.g. mcp-memory-service ≈60 KB of tool definitions, mnemosyne 41 tools ≈42.7 KB — reviewers' estimates).
3. **LLM-in-the-loop capture is expensive and slow.** claude-mem runs an observer model per tool call; mem0/EverOS/Honcho need a model per write. Deterministic capture (context-mode, ai-memory, pro-workflow's inline [LEARN] blocks) gets most of the value for free.
4. **Repeats are pure waste.** Only a few (ReMe, OpenViking, magic-context) track what was already shown in a session.
5. **Tool output, not memory, is often the biggest context hog.** context-mode and openwolf showed 90%+ savings by sandboxing/condensing command output.
6. **Lexical-first hybrid is enough to start.** agent-memory, ai-memory, mcp-memory-service and ReMe report strong recall with BM25/FTS5 alone; embeddings add a few points at 10–30× latency.
7. **Cross-agent coverage is uneven.** Most projects are Claude-Code-first; few cover Codex hooks, Gemini CLI hooks, Antigravity's PreInvocation/injectSteps and OpenCode plugins from one spec.
